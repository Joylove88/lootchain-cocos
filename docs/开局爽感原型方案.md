# 开局爽感原型(`?opening=v2`)实现方案

> 2026-11-27 · 只做三步走的第 ① 步。全部在开关后面:网址不带 `?opening=v2` 时,游戏和线上一字不差。
> 只本地提交前端仓 main,不发线上、不动后端、不改数值表(第 4 节的数值改动等你点头再做)。

## 0. 现状:新号多久才打第一场「像样的仗」

建角确认 → 序幕视频(约 15 秒)→ 进村 → 觉醒演出 → 契约之选 → 移动教学(走 3 步)→ 找村长对话(V01)→ 训练场按键教学打稻草靶(V02)→ …… → 出村到林地才第一次打真怪。
晨风村本身**只有 3 个稻草靶,没有一只真怪**。第一场有反馈的战斗在几分钟之后(第 4 节有分段时间)。

## 1. 新流程(开关打开时)

```
登录 / 注册 → 选择主角(不变)→ 点「确认」
  → 进晨风村,约 3 秒加载后直接开打「前世一战」(跳过序幕视频 / 觉醒演出 / 剧情对话)
  → 2~3 分钟满配强队打兽潮
  → 首领倒下:慢放 + 一句话收尾 → 黑场 0.8 秒
  → 回到晨风村 Lv.1 正常开局:契约之选 3 选 1 → V01 起照常(移动教学跳过,已经会走了)
```

- **一句话的设定**(不做过场,只是战斗开始 / 结束各一行字,零的口吻):
  - 开场:「这是你前世的力量——借你一战。」
  - 收尾:「力量睡着了。从这里开始,把它找回来。」
  - 这样「回到 1 级」不是落差,是目标:玩家知道满配长什么样,后面每一级都在往回找。和 docs/59 / 60 的「前世夜帝」设定一致。
- **开局包体积**:晨风村地图、主角骨骼都已在开局包;原型新增要用的 3 名 UR 英雄骨骼 + 3 套大招特效 + 3 种怪物骨骼。本地预览不受影响;将来要上线时这些要进开局包(源文件约 30MB,出包压缩后会小很多,上线前再量)。

## 2. 「前世一战」怎么做(复用现有野外战斗)

做法照搬已经上线的「心魔试炼」:在当前地图上就地开一个战斗模式,结束原样恢复。全部在 `LobbyTownRenderer` 里加一个 `opening` 模式 + 一个新文件管波次 / 掉落表现,**不新建场景、不发任何战斗请求**。

| 项 | 做法 | 复用 |
|---|---|---|
| 场地 | 晨风村村口广场(传送阵一带,地面开阔);开战时收起 NPC / 物件 / 训练靶 / 任务追踪 / 小地图 / 系统按钮(白天打,不压夜色:人要看得清) | 心魔试炼的「收起 → 恢复」 |
| 队伍 | 主角(炼魂装 + 「夜帝残影」大招)+ 3 名 UR:**奥蕾莉亚**(射手,万箭裂空)、**伊芙琳**(法师,冰狱湮灭)、**妮克丝**(刺客,千夜追猎)。都是西式立绘、各带满屏大招包 | 野外队伍 / 援护 / 换队长 / 大招特效全套 |
| 手感 | 攻击力按「普攻一刀清一片小怪」设定;普攻范围 ×1.5;技能冷却 3 秒、援护 8 秒、夜帝残影 10 秒;主角不会死(血量最低保 30%) | 连招 / 顿帧 / 震屏 / 击退 |
| 怪 | 4 波兽潮从广场四周涌进来:幼鼠 + 蛛群 → 野犬群 → 3 只棕鬃熊精英 → 首领「腐木巨熊」(带读条重击红圈,教翻滚)。同屏控制在 25 只左右(手机骨骼数) | 野外怪物 AI、精英读条重击、首领登场 |
| 伤害数字 | 字号放大 1.4 倍,暴击 / 大招再大一号金色;同一只怪的数字照现有规则错开 | 现有飘字 |
| 连杀计数 | 屏幕右侧大号「连杀 ×37」,3 秒不杀断档;25 / 50 / 100 档变色 + 零喊一句 | 新做(纯显示) |
| 教学 | 开场 1 句:「拖左边走 · 点右边打 · 亮了的技能放出去」(电脑端显示 WASD / J / K L I);大招转好时按钮外圈闪一下。**不单独占环节** | 现有弱引导气泡 / 按钮光环 |
| 结束 | 首领倒下 → 0.6 秒慢放 + 重震 → 收尾一句 → 黑场 → 恢复村子、队伍换回真实名册(只有主角)、Lv.1 | 心魔试炼结束流程 |

**时长**:4 波按清完推进,每波约 30~45 秒;总上限 3 分钟(到点首领直接登场)。

## 3. 掉落有期待(本原型全部是假的,只做表现)

- 品质 5 档:白 / 绿 / 蓝 / 紫 / 橙。小怪约 30% 掉东西,精英必掉蓝以上,首领必掉 1 件橙 + 2 件紫。
- 表现:
  - 白 / 绿:地上一个带色光圈的小图标,0.5 秒后自动飞向队长;
  - 蓝:加一道细光柱;
  - 紫 / 橙:粗光柱 + 落地「叮」声 + 光柱停 1.2 秒再吸附;橙色额外轻震屏;
  - 拾取时队长头顶飘名字(品质色):「【紫】渡鸦之牙」「【橙】长夜王冠」。
  - 右上角小卡片累计本场战利品(复用「本轮战果」卡)。
- **哪些是假的**:名字、图标、品质全部客户端随机,**不进背包、不发奖励、不调接口**;战斗不登记遭遇、不上报击杀;不进服务端复演。收尾时零说一句「前世的东西带不走」,避免玩家回去找。
- 图标复用现有装备图标(`ui/equip`,已在开局包)。
- 真掉落带随机词条是第 ② 步,这次不做。

## 4. 前 10 分钟节奏(先列现状,数值改动等你点头)
